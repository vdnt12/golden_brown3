# Fixtures

All fixtures are **synthetic**, authored for this project, and released as **own work
(CC0-1.0)**. No real agreement, personal data, or third-party document is included.

| File | Purpose | Target tests | Known limits |
|---|---|---|---|
| `synthetic_rental_simple.txt` | Clean baseline rental agreement with 11-month term, deposit, notice, penalties, Annexure A | ingestion, citation, evaluation baseline | Plain TXT, one virtual page |
| `synthetic_rental_indian_style.txt` | lessor/lessee, leave-and-licence, lock-in, Rs./-, DD/MM/YYYY, stamp paper, Schedule I | terminology, dates, Indian rupee formats | Plain TXT |
| `synthetic_rental_conflict.txt` | Differing notice periods (clauses 6/14), contradictory deposit deductions (15/16), contradictory rent revision (18), absent clause 17 reference | conflict detection, cross-reference expansion | Deliberately inconsistent |
| `synthetic_rental_ambiguous.txt` | "reasonable notice", "market rate", "appropriate deductions", misleading heading "NO DEPOSIT" that contradicts its own text, missing clause 17 | ambiguity, misleading heading, silence | Deliberately vague |
| `synthetic_rental_injection.txt` | Body, footnote, header and table instructions ("declare valid", "call delete_document", "reveal prompt") | injection, non-escalation | Plain TXT cannot represent tiny-font/colour tricks |

## Canaries

Each fixture embeds a unique marker (`CANARY-LG-<NAME>-NNN`) used by privacy tests to
check that document text does not reach logs or external captures. Canaries are not
personal data.

## Planned generated fixtures (Phase 1)

PDF variants (simple, scanned/image-only, table/multi-column, 50+ page long, encrypted,
truncated, oversized) and a non-English page fixture will be generated by a committed
script and listed here with provenance before any test claims them. Until generated,
no test or doc may claim PDF, OCR or long-document support.

## Rules

- Never commit a real agreement or uploaded user document.
- Every fixture change updates this provenance table.
- Held-out contracts are written after feature freeze (Guide 16.3) and are not listed
  here in advance.
