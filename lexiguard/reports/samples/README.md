# Sample payloads

Generated by `python3 scripts/generate_samples.py` — the same service functions the
HTTP routes call, against `fixtures/synthetic_rental_conflict.txt`. They are not
hand-written.

| File | Produced by | Shape |
|---|---|---|
| `overview_conflict.json` | `build_overview` | `document`, `cards` object with 11 label keys, `warnings` |
| `review_conflict.json` | `build_review` | `review_status`, `attention_first` (priority-ordered), `questions_for_professional` |
| `ask_conflict_silent_model.json` | `answer_question` + a provider that returns no points | `INSUFFICIENT_EVIDENCE`, 0 claims |

The ask sample shows the honest empty case: retrieval found rent wording, the provider
returned nothing, and the answer is `INSUFFICIENT_EVIDENCE` with zero claims rather than a
guess. The provider is a test double, **not** a language model.

Document ids and hashes come from a temporary run and will not resolve in your installation.
Regenerate after any contract change; do not edit by hand.
