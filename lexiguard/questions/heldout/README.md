# Held-out questions

Held-out contracts and their questions are written **after feature freeze** by a person
who did not author the lexicon, prompts or the development fixtures (Guide 16.3), and
are never referenced in application code. Nothing is committed here in advance.

The development set in `../development.jsonl` is a 12-row starter with draft annotations.
The Guide requires at least 100 ground-truthed questions (144 at Tier 2) with gold sids,
expected facts, forbidden claims and independent review before the final evaluation.
Do not treat the starter rows as evaluated results.
