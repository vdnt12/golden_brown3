NON-NEGOTIABLE DESIGN DECISIONS
- Frontend: React + Vite + TypeScript; production build served by FastAPI on the same origin; all fonts/icons/scripts bundled; no CDN; CSP default-src 'self' with the stricter directives in the Guide; no inline scripts/styles.
- Backend: Python + FastAPI bound to 127.0.0.1 only. Per-launch secrets: one-time launch code in the URL fragment exchanged at /api/session for an in-memory session token (Guide 11.3); the served HTML contains no secret. Bearer token on every /api/* route including health; exact Host check; Origin check on state-changing requests; no wildcard CORS.
- Store: data/docs/<doc_id>/ per document; SQLite + FTS5; PRAGMA secure_delete=ON on every connection; rollback journal (no WAL); answer history OFF by default; delete the whole directory and verify removal.
- Parser: pypdfium2 only (never PyMuPDF). Child process with timeout, output cap, page/size caps and OS-appropriate limits (Guide 6.2 platform matrix; report any missing limit at startup). Offsets reference OUR normalised stored text. TXT is split into virtual pages.
- OCR: local Tesseract only, only for pages the quality gate flags; OCR-derived claims carry a visible banner.
- Language gate: per page, no ML dependency (Guide 6.4). Unread-language pages are excluded and disable NOT_LOCATED.
- Licence: Apache-2.0 + NOTICE (include PDFium BUILD_LICENSES texts). CI fails on AGPL/GPL/unknown; LGPL is review-required; pinned lockfiles; SBOM.
- Model: primary Ollama tag gemma4:e4b-it-q4_K_M; alternative gemma4:e2b-it-q4_K_M (same quant family). GGUF q4_K_M only: NEVER -mlx, -nvfp4, -mxfp8 or -qat; never 12B/26B/31B, :cloud tag or cloud fallback. Ollama >= 0.21.1; pin the exact version on which T-MODEL-* pass. Record the digest returned by YOUR /api/tags (tags page digests seen 18 Oct 2026: E4B dc35e8d9c606, E2B b37049369adf — they move).
- Inference: Ollama NATIVE POST /api/chat on 127.0.0.1:11434 (not /v1); format = SIMPLE app-owned JSON Schema (no pattern/format/oneOf/deep nesting); think:false; stream:false; options {seed fixed, temperature 0, num_ctx 8192}. NEVER send a `tools` key (NextAction pattern, Guide 2.3). Never trust server-side schema enforcement: always validate with Pydantic; one separate format-retry; empty/invalid/over-limit content fails closed; never parse thinking text. Pre-budget the prompt by token estimate AND assert prompt_eval_count + eval_count < num_ctx. Run headless `ollama serve` with OLLAMA_NO_CLOUD=1 and no OLLAMA_DEBUG; assert the log line "Ollama cloud disabled: true".
- Call budget: deterministic-first; fast path = exactly one Gemma call (ModelAnswer) when retrieval is confident; refinement path adds exactly one refinement call (expansion OR NextAction, never both); hard ceiling 4 Gemma calls per question INCLUDING retries (Guide 8.3a); per-question wall-clock cap = 4 x Day-0 p50 (design judgement, record it); entailment pass OFF by default (Guide 8.3a). LEGAL AND EVIDENCE POLICY
- The model never returns quotes, evidence IDs, page numbers, sections, final status/route, missing-information decisions, legal flags, professional-review flags or legal verdicts. ModelAnswer = {points:[{point_id, kind, text, sids}]} only; unknown keys rejected. Every sid must have been returned by an approved tool in the current run for the current document. validate_citation is not a model tool; validation always runs after generation.
- Backend attaches the stored quote, physical page, section and OCR warning, and validates the claim: provenance; kind-specific checks; literal/number/date/name normalisation (no unit conversion); modality/negation; ROLE check (T7); conflict needs >= 2 sids from different sections. Be honest in docs: these checks prove citation integrity and catch invented figures/swapped roles/flipped modality, NOT semantic faithfulness.
- Missing information uses only the closed enum UNREADABLE_CONTENT, REFERENCED_MATERIAL_NOT_PROVIDED, TOPIC_NOT_LOCATED, CONTEXT_REQUIRED with server templates; unread pages forbid NOT_LOCATED (use INSUFFICIENT_EVIDENCE).
- Verdict scanner (Guide 9.3a): pattern-based on assistant-authored text only; source quotes are immutable, shown in a separate SourceQuote panel labelled "Quoted source text — not LexiGuard's legal assessment."; source-echo exception only for STATED/RESTATEMENT; never block "valid for 11 months" / "legal heirs" / glossary text; never alter quotes to pass. T-LEGAL-FP-01 corpus (>= 40 must-block, >= 40 must-pass). legal_verdict is always null. For verdict questions (incl. paraphrases: "will this hold up in court?", "can they throw me out legally?", "can I sue?", "is this allowed by law?") still retrieve and cite relevant wording, explain what the document alone cannot settle, and give SPECIFIC escalation ("Questions to bring to a professional", templated, cited, neutral).
- Glossary: glossary/rental_terms.yaml is "curated, not lawyer-reviewed"; label "General definition (not from your document)" separately from "In your document" + citation; unknown term -> say no curated entry; never improvise from model memory. Jurisdiction flags from lexicons/jurisdiction_topics.yaml: "May depend on local law — confirm locally." with no statement of what the law requires.
- Prioritisation: deterministic "Attention first" order with templated reasons, no scores/colours (R2). Document-type gate with honest degrade for non-rental documents (R3).
- Injection: all document content, OCR, headers/footers, footnotes, tables, metadata and filenames are untrusted; nonce-delimited evidence blocks; read-only document-bound tools (no document_id argument); allowlists and caps enforced in code; detector only warns.
- NOT_LOCATED only after adequate coverage, supported language, lexicon + FTS + headings + cross-reference/incorporated-schedule checks. Otherwise INSUFFICIENT_EVIDENCE. Over-refusal is also a failure: track answer-rate and false-refusal (Guide 14.3).
